# Portfolio CRM Dashboard

A modern, responsive, and beautifully designed CRM Dashboard built with the MERN stack (MongoDB, Express, React, Node.js). 

## 🚀 Features

- **Interactive UI**: Built with React and Framer Motion for smooth animations and transitions.
- **Modern Design**: Styled using Tailwind CSS for a premium and aesthetic look.
- **Client & Server Architecture**: Clean separation between the frontend (Vite + React) and backend services.
- **Responsive Navigation**: Fully responsive layouts adapted for any device.

## 🛠️ Technology Stack

**Frontend:**
- [React 19](https://react.dev/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS 4](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)
- [Lucide React](https://lucide.dev/) (Icons)
- [React Router DOM](https://reactrouter.com/)

**Backend:**
- Node.js & Express
- MongoDB (Mongoose)

## 📦 Getting Started

### Prerequisites
- Node.js installed on your machine
- MongoDB running locally or a MongoDB URI

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/aman8825/PORTFOLIO_CRM.git
   cd PORTFOLIO_CRM
   ```

2. **Install Client Dependencies:**
   ```bash
   cd client
   npm install
   ```

3. **Install Server Dependencies:**
   ```bash
   cd ../server
   npm install
   ```

### Running the Application

To run the application locally in development mode:

**Start the Server:**
```bash
cd server
npm run dev
```

**Start the Client:**
```bash
cd client
npm run dev
```

The frontend will be available at `http://localhost:5173`.
